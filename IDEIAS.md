## 🎮 Gameplay

- **Modo Tabuada Invertida:** mostrar o resultado, usuário digita os dois fatores (ex: "= 24", resposta: "4 × 6" ou "3 × 8")
- **Modo Frenesi:** 5 segundos por pergunta, resposta errada = -10 pontos (ao invés de vida)
- **Modo Boss Battle:** responder X perguntas corretas antes do timer do "chefe" acabar
- **Power-ups:** itens especiais (tempo extra, pular pergunta, etc.) desbloqueados com streak
- **Modo Zen:** sem timer, sem pressão, modo treino livre sem pontuação (para aprender antes de competir)

## 🎨 Visual

- **Tema Neon/Cyberpunk:** versão dark mode com cores neon
- **Animação de "nível subindo":** explosão de partículas ao subir de nível
- **Mascote:** criar um personagem para o app (pequeno matemático?)
- **Combo visual mais épico:** texto "INSANE COMBO!" com tremida de tela

## 📊 Analytics & Progressão

- **Mapa de pontos fracos:** visualização de quais tabuadas o usuário erra mais (ex: heatmap 10×10)
- **Streak calendar:** calendário tipo GitHub contributions mostrando dias jogados
- **Tempo médio por resposta:** gráfico de velocidade ao longo do tempo
- **Curva de aprendizado:** mostrar quais multiplicações melhoraram ao longo das semanas

## 🤝 Social

- **Share Card:** gerar imagem para compartilhar no WhatsApp ("Fiz X pontos no Tabuada Rush!")
- **Desafio de amigo:** gerar link com seed do desafio do dia para amigo jogar
- **Ranking entre amigos:** lista de amigos e recordes comparados

## 🧠 Educacional

- **Dica de multiplicação:** ao errar, mostrar um truque mnemônico (ex: "9×x: subtraia 1 do x e complete até 9")
- **Histórico de erros:** lista das multiplicações que mais errou esta semana
- **Modo revisão:** focar apenas nas multiplicações com maior taxa de erro

## 🔧 Técnico

- **Sync com nuvem:** Firebase ou Supabase para dados cross-device
- **PWA install prompt:** mostrar banner para instalar como app
- **Web Workers:** cálculo de stats pesadas em background thread
