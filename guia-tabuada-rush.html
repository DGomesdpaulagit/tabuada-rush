01
O que você precisa
Nenhum programa especial. Só isso aqui abaixo.
✓
Um navegador de internet
Chrome, Firefox, Edge, Safari — qualquer um funciona. O jogo é um arquivo HTML puro, ele roda direto no navegador, sem precisar de internet depois de baixado.
✓
O arquivo do jogo (tabuada-rush.html)
Você já tem ou vai baixar agora. É só 1 arquivo. Não precisa instalar nada, não precisa de servidor, não precisa de internet.
Dica importante
O jogo funciona 100% offline. Depois de baixar, você nunca mais precisa de internet para jogar. Seu progresso (XP, recordes, nível) fica salvo automaticamente no navegador.
02
Baixar o arquivo do jogo
Você recebeu o arquivo tabuada-rush.html aqui no chat.
1
Encontre o arquivo no chat
Role a conversa para cima e procure a mensagem onde aparece o link tabuada-rush (com ícone de arquivo).
2
Clique no arquivo para baixar
Clique no nome do arquivo ou no botão de download. O navegador vai baixar o arquivo tabuada-rush.html para a sua pasta de Downloads.
3
Mova para uma pasta que não vai deletar
Importante: a pasta Downloads é limpa às vezes. Crie uma pasta segura para o arquivo não sumir. Veja abaixo:
📁 Documentos └── 📁 Meus Jogos └── tabuada-rush.html ← coloque aqui
Atenção
Não renomeie o arquivo. Não mova ele depois de criar o atalho. Se mover, o atalho para de funcionar. Deixe na pasta definitiva antes de criar o atalho.
03
Abrir e jogar no computador
Windows, Mac ou Linux — funciona em todos.
1
Abra o Explorador de Arquivos
No Windows: pressione as teclas Windows + E ao mesmo tempo. No Mac: clique no ícone do Finder na dock.
2
Navegue até a pasta onde salvou o arquivo
Por exemplo: Documentos → Meus Jogos → tabuada-rush.html
3
Dê dois cliques no arquivo
O arquivo vai abrir automaticamente no seu navegador padrão. Pronto — o jogo já está rodando!
tabuada-rush.html — Seu navegador
A barra de endereço vai mostrar algo como:
file:///C:/Users/VoceMesmo/Documentos/Meus Jogos/tabuada-rush.html

Isso é normal. O file:/// significa que está abrindo um arquivo local do seu computador. O jogo vai funcionar perfeitamente assim.
Dica
Para abrir mais rápido na próxima vez, use o atalho na área de trabalho. Veja o passo 06.

Usar no celular
Android e iPhone — sem instalar app nenhum.

Envie o arquivo para o seu celular
Você tem 3 opções fáceis:
  • 📧 Email: mande o arquivo para você mesmo e baixe no celular

  • ☁️ Google Drive / iCloud: suba o arquivo e baixe no celular

Salve o arquivo tabuada-rush.html nos Downloads do celular.

Android: Abra o app Arquivos → Downloads → toque no arquivo tabuada-rush.html → escolha "Abrir com Chrome (ou outro navegador)".

Atenção — Android
Se aparecer "Não é possível abrir", toque e segure o arquivo → "Abrir com" → escolha Chrome ou outro navegador. Não abra com apps de gerenciador de arquivos — só com o navegador.
05
Atalho na tela inicial do celular
Para abrir o jogo com 1 toque, igual a um app.
1
Abra o arquivo no Chrome (Android) ou Safari (iPhone)
Siga o passo 04 acima e deixe o jogo aberto no navegador.
2
Android — Chrome
Toque nos 3 pontinhos (⋮) no canto superior direito → toque em "Adicionar à tela inicial" → confirme. Vai aparecer um ícone na sua tela inicial igual a um app.

Agora o Tabuada Rush vai aparecer na sua tela inicial igual a qualquer outro app. Toque uma vez para jogar. Sem abrir navegador, sem procurar arquivo.

07
Como o progresso é salvo
Entenda para nunca perder seu XP e recordes.
!
O jogo salva no navegador — não no arquivo
Seu XP, nível e recordes ficam salvos no armazenamento local do navegador (localStorage). O arquivo HTML em si não muda.
!
Sempre use o mesmo navegador
Se você joga no Chrome e abre no Firefox, o progresso não vai aparecer. Use sempre o mesmo navegador para acumular XP.
!
Não limpe dados do navegador
Se você limpar "histórico e dados do site" ou "cookies e dados armazenados" no navegador, o progresso do jogo é apagado. Evite limpar esses dados se quiser manter o histórico.
Resumo simples
Mesmo navegador + mesmo computador = progresso sempre lá. Isso não é um bug — é como todos os jogos offline no navegador funcionam.
08
Solução de problemas comuns
Se algo não funcionar, resolva com esses passos.
P1
O arquivo não abre / abre como texto estranho
Isso acontece quando o arquivo é aberto com um editor de texto. Solução: clique com botão direito no arquivo → "Abrir com" → escolha Google Chrome, Firefox ou Edge.
P2
Fonte estranha / letras diferentes
O jogo carrega fontes do Google Fonts. Se estiver sem internet, usa uma fonte padrão. Funciona normalmente, só muda a aparência levemente.
P3
Meu progresso sumiu
Possíveis causas: usou um navegador diferente, limpou dados do navegador, abriu o arquivo de um lugar diferente, ou usou modo anônimo. Solução: sempre abra o mesmo arquivo no mesmo navegador, sem modo anônimo.
P4
O celular não abre o arquivo
Tente abrir com o Chrome especificamente: abra o Chrome → toque na barra de endereço → digite file:/// e navegue até o arquivo. Ou use o método do Google Drive (passo 04).
P5
O timer não está contando / travou
Recarregue a página com F5 (PC) ou puxe para baixo (celular). Se persistir, feche a aba e abra o arquivo de novo.
09
Como jogar — guia dos modos
Entenda cada modo e quando usar cada um.
⚡
Modo Rush — recomendado para o dia a dia
Começa com 5 minutos. Cada acerto dá +1 segundo extra. Quanto mais acertar, mais tempo ganha. A dificuldade sobe sozinha: começa com tabuada do 2 ao 5, depois vai até o 10. Use este modo todo dia.
❤️
Modo Sobrevivência — desafio
Sem tempo, mas você tem só 3 vidas. Errou 3 vezes, acabou. Ótimo para testar se realmente memorizou. Use 1-2x por semana para se desafiar.
⏱
Modo Velocidade — reflexo
Só 60 segundos, sem bônus de tempo. Máxima pressão. Use para treinar rapidez quando já souber a tabuada bem.
📅
Modo Desafio Diário — rotina
5 minutos fixos, sequência organizada. Ideal para começar o dia. Sem bônus de tempo — é o modo mais "limpo" para meditar sobre os acertos.
🔥
Sistema de COMBO e Sequência
A partir de 3 acertos seguidos, aparece o badge de sequência. A cada 5 acertos sem errar, aparece o COMBO no meio da tela. Errou? A sequência zera. Isso é propositalmente viciante — aproveite.
⬆️
Sistema de XP e Nível
Cada acerto dá XP. Acertos em nível de dificuldade maior dão mais XP. Você passa por 7 níveis: Iniciante → Aprendiz → Calculador → Ágil → Expert → Mestre → Lenda. A barra de XP fica na parte de baixo durante o jogo.
10
Rotina diária recomendada
O segredo da memorização é a repetição constante.
Rotina de 10 minutos por dia
  • Dias 1 a 7 — Use só o Modo Rush. Foque em acertar mais rápido cada dia. Não se preocupe com o nível de dificuldade subindo.
  • Dias 8 a 14 — Alterne: Rush pela manhã, Sobrevivência à noite. Compare seus recordes.
  • Semana 3 em diante — Tente bater seu próprio recorde de pontos no Rush. Use o Velocidade para sprint rápido de 60 segundos.
  • Todo dia — Olhe a tela de Recordes (botão no menu). Veja seu nível subindo. Isso mantém a motivação.
Por que funciona
5 a 10 minutos por dia é mais eficiente do que 1 hora por semana. O cérebro memoriza por repetição distribuída. A tabuada vai virar reflexo automático em 2 a 4 semanas de uso diário.
